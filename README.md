# 엑셀 이미지 삽입기 — 다운로드

엑셀(.xlsx/.xlsm)의 칸에 이미지를 끌어다 놓으면 칸 크기에 맞춰 넣고 바로 저장하는 프로그램입니다.

**[최신 버전 다운로드 →](https://github.com/kwon0281m/images-to-excel/releases/latest)**

| 파일 | 용도 |
|---|---|
| `ImagesToExcel-Setup-*.exe` | **Windows 설치 프로그램** |
| `ImagesToExcel-*-portable.zip` | Windows 설치 없이 사용 (압축 풀고 ImagesToExcel.exe 실행) |
| `ImagesToExcel-*.dmg` | **macOS** (Apple Silicon) — 앱을 Applications로 끌어 놓기 |

설치한 프로그램은 새 버전이 나오면 자동으로 알려 주고 업데이트합니다.

이 저장소는 설치 파일 배포 전용입니다.
